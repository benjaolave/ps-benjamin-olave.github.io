# Landing de psicoterapia online especializada en duelo y trauma — versión 1

Esta versión conserva la orientación para pacientes en Chile y organiza el mensaje con una narrativa más clara: reconocer la experiencia de duelo, explicar el enfoque, mostrar un camino terapéutico flexible y facilitar la decisión de reservar una evaluación inicial.

## Archivos
- `index.html`: estructura, textos, preguntas frecuentes, enlaces y Meta Pixel.
- `style.css`: diseño adaptable a escritorio y móvil.
- `hero-benjamin.jpg`: fotografía profesional que ya se utilizaba en la landing anterior.

## Publicación en GitHub Pages
1. Haz una copia de seguridad de la landing actual.
2. Sube estos archivos a la raíz del repositorio que publica `benjaolave.com`, reemplazando el `index.html` y `style.css` actuales y conservando el archivo `CNAME` del repositorio.
3. Conserva `hero-benjamin.jpg` en esa misma raíz para que cargue la fotografía.
4. Espera la publicación de GitHub Pages y comprueba la web tanto en escritorio como en móvil.
