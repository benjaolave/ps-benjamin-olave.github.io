# Landing de Benjamín Olave — versión Chile v2

Esta versión mantiene el servicio como psicoterapia online individual especializada en duelo y trauma. Actualiza la composición visual con una paleta marfil, terracota y verde salvia, presenta el camino terapéutico en etapas visualmente diferenciadas y separa la historia personal de la formación y el enfoque clínico.

## Archivos
- `index.html`: textos, estructura, valores, preguntas frecuentes, enlaces y Meta Pixel.
- `style.css`: estilos de escritorio y móvil.
- `hero-benjamin.jpg`: fotografía actual del encabezado. No se incorporaron fotografías nuevas; quedan pendientes para una siguiente iteración.

## Cómo actualizar GitHub Pages
1. Haz una copia de seguridad de los archivos que tienes publicados actualmente.
2. Descomprime este ZIP.
3. En el repositorio que publica `benjaolave.com`, sube los tres archivos de este ZIP a la raíz y reemplaza `index.html`, `style.css` y `hero-benjamin.jpg`.
4. **No elimines ni reemplaces `CNAME`** ni modifiques la configuración de GitHub Pages.
5. Una vez publicada la versión, revisa la página tanto en escritorio como en móvil y haz clic en los enlaces de reserva.
