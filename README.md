# Landing internacional de Benjamín Olave

Esta carpeta crea una versión internacional separada de la landing, pensada inicialmente para el público de España. Conserva el diseño, los testimonios, la estructura, los enlaces de Encuadrado y la configuración actual del píxel de Meta; solo actualiza la identificación inicial del servicio, el precio y las preguntas frecuentes internacionales.

## Cómo publicarla en GitHub Pages

1. Descomprime el archivo ZIP.
2. Sube la carpeta completa `internacional` al repositorio actual, al mismo nivel que el `index.html` de la raíz.
3. **No reemplaces el `index.html` de la raíz.** Así la landing chilena permanece sin cambios.
4. Cuando GitHub Pages publique los cambios, la versión internacional debería quedar en `https://benjaolave.com/internacional/`.

## Contenido

- `index.html`: texto de la landing y preguntas frecuentes.
- `style.css`: estilos de la página (incluye la tarjeta única de precio).
- `hero-benjamin.jpg`: imagen usada por la página.

La página conserva el píxel Meta `1481440616899371`, el evento personalizado `ClickAgendaEncuadrado` y los enlaces a `https://encuadrado.com/p/benjamin-olave`.
