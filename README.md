## Antes de publicar
1. Reemplazar los dos placeholders de fotografía por tus imágenes.
2. Revisar textos, formación y datos de contacto.
3. Subir `index.html` y `style.css` al repositorio de GitHub.
4. Activar GitHub Pages desde Settings → Pages.
